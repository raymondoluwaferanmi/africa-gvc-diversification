# GVC Participation and Industrial Diversification in Sub-Saharan Africa

**A Shift-Share Instrumental Variable Analysis**

## Research Question

Does deeper participation in global value chains (GVCs) catalyze industrial
diversification in Sub-Saharan Africa, or does it reinforce specialization in
low-value-added primary commodities? This project provides causal estimates
using a shift-share (Bartik) instrument that exploits global sectoral demand
shocks interacting with countries' pre-determined export composition.

## Key Features

- **Data**: OECD Trade in Value Added (TiVA), UN Comtrade, World Bank WDI,
  Harvard Atlas of Economic Complexity
- **Method**: Two-stage least squares with a shift-share instrument; panel
  fixed effects; heterogeneity analysis by resource-intensity and geography
- **Robustness**: Alternative instruments, pre-trend tests, placebo outcomes,
  subsample analysis
